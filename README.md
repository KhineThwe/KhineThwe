## 🔬 Featured NLP projects

| Project | What it shows | Key result |
|---|---|---|
| [**myPolar: Burmese online polarization detection**](https://github.com/KhineThwe/-myPolar-Burmese-Online-Polarization-Detection) | Group project (12 members, lead presenter). Built a 10,955-sentence Burmese corpus from 23 annotators and compared traditional ML, Bi-LSTM, Transformer, mBERT and XLM-RoBERTa on the three POLAR (SemEval-2026 Task 9) subtasks. | Best detection macro-F1 **0.802** (XLM-RoBERTa). Keeping Burmese syllables whole raised macro-F1 from 0.63 to 0.80. |
| [**Myanmar ↔ Hiero neural machine translation**](https://github.com/KhineThwe/Myanmar-Hiero-Neural-Machine-Translation-with-Marian) | Individual project with Marian NMT: over 20 seq2seq and Transformer experiments, tuning, ensembling, and a segmentation study. | Word segmentation cut test OOV from 33.2% to 1.8% and raised BLEU from **12.6 to 31.2**. |
| [**Burmese NER with a linear SVM**](https://github.com/KhineThwe/Burmese-Named-Entity-Recognition-with-a-Linear-SVM) | LinearSVC taggers on myNER, with and without POS features. | Accuracy **0.981**, within 0.001 of the published best. |
| [**Burmese word segmentation with CRF**](https://github.com/KhineThwe/burmese-crf-word-segmentation) | CRFsuite segmenter trained on myPOS v3.0. | Syllable-level accuracy **0.983**. |

**The common thread:** in both classification and translation, how Burmese text is split into units mattered more than which model was used.
